# TUBO Slow Stock Action Tool

## Project Overview
This project is a browser-based tool developed for the TUBO Technology & Data Management case study. It helps users review slow-moving inventory, identify stock that needs action, and find potential customer targets.

## Live Demo
https://khyatisahu2211-sketch.github.io/tubo---slow---stock---tool/

## Features
- Upload a combined Excel workbook.
- Review inventory under Red List, No Action, and Push categories.
- View aged stock quantities and values.
- Identify potential customer targets for Push items.
- Highlight data-quality issues for review.
- Download item review and customer target results as CSV files.

## Technology Used
- HTML
- JavaScript
- SheetJS for reading Excel workbooks
- GitHub Pages for free hosting

## How to Use
1. Open the live demo link.
2. Upload the case-study Excel workbook.
3. Click the analysis button.
4. Review item classifications, customer targets, and data-quality warnings.
5. Download the available results.

## Important Note
The case-study data is illustrative. Review all warnings and confirm business rules before taking inventory or sales actions.
